# Scripting Strategy Examples

This folder contains functional Lua examples matching the original Go-based hardcoded strategies (Grid, Bollinger, Scalping).

## How to use:
1. Open the **Script Editor** in the UI.
2. Copy the contents of one of these `.lua` files.
3. Paste it into the editor.
4. Modify symbols, thresholds, and indicators as needed.
5. Preview against recent candles and hit Save!
